# animation-engine extension

The home for UnysonPlus's animation capabilities — WebGL objects, scroll motion, hover/physics interactions, text effects, backgrounds, cursors, page transitions and a seamless-scroll loop. **Active by default:** no (ships INACTIVE — activate it under Extensions).

## Provides

- **Shortcodes (9):** `gallery-3d` (Motion Gallery), `image-scroll-choreography`, `text-scroll-choreography`, `image-sequence`, `interactive-reveal`, `model-viewer`, `svg-draw`, `svg-morph`, `webgl-object` → see `../shortcodes/` for each element's atts.
- **Shared scroll-choreography engine + authoring guide:** the Image/Text Scroll Choreography elements share one pose engine (`includes/scroll-choreo/`) that scrubs `.fw-choreo__layer` from scroll; and a shared, logged-in-only **authoring guide** HUD (`includes/anim-guide/`, `window.upwAnimGuide`) — numbered, hue-tinted, stacking, collapsible, click-to-flash — is reused by both the Scroll Choreography and Model Viewer guides so they read as one overlay and co-stack. The guide also carries an opt-in **Tier 3 editor** (the `✎` toggle, wired for Scroll Choreography): a **scrub playhead** freezes the scene at any % without scrolling; each layer gets a **keyframe track** (a 0–100% ruler with a draggable diamond per keyframe) — **drag** to retime, **click** to select + scrub-to, **double-click** the track to add a keyframe (interpolated pose, so the curve is unchanged), **Delete key** to remove one (min 2 kept); per-field **± steppers** nudge the selected keyframe live; and **Copy keys** serialises the edited keyframes to the clipboard. Pasting that JSON into the element's **Custom keyframes** field (Advanced tab, both Scroll Choreography elements) drives it from those exact keyframes verbatim — **overriding the Recipe and each layer's Appear/Hold/Exit** (values are coerced + re-sorted server-side; the `data-keys` attr is JSON-encoded + escaped, so a paste can't inject markup) — closing the author round-trip. The whole HUD is **draggable by its `⠿` grip** (pops out of the bottom-right stack, pins anywhere). The editor is engine-agnostic (`create({ editor:{ steps, onScrub, onLive, onNudge, onCopy, getTracks, onKeyMove, onKeyAdd, onKeyDelete } })`) so other scroll-driven elements can adopt it.
- **Tier 1 recipes (one-click compositions):** both Scroll Choreography elements carry a **Recipe** select on their first tab. Pick a recipe and just add images/lines — at render the recipe drives every layer's anchor + appear/hold/exit choreography from a pattern indexed by position and **staggered automatically across the Scroll Length** (so any number of layers composes), preserving the author's own image/text (+ inset/z/flip/warp/effect). `custom` (default) keeps each layer's hand-authored controls. Image recipes: `parallax_rise` · `corner_peek` · `zoom_focus` · `diagonal_sweep` · `alternating_sides`. Text recipes: `stacked_rise` · `alternating_sides` · `center_focus` · `diagonal_sweep`. Recipe tables live in each element's `views/view.php` (slots + timing), so adding a recipe is a data edit.
- **Effects/modules:** dozens of effect families attached via the element **Animations** tab, to Sections, or site-wide (hover, physics, text-effects, scroll-motion, scroll-reveal, motion-path, scroll-text-highlight, parallax, marquee, and more), plus site-wide **smooth-scroll** (Lenis inertia) and CSS-utility modules (`viewport-units`, `scroll-var`) → see `../animation-engine/` for the full inventory.
- **Scroll-flow modules (Section-level choreography):** `motion-sequence` (children's Reveal/Stagger play as ONE timeline), `scrollytelling` (pinned scene stage with a frame/video/image backdrop), and `sticky-stack` → see `../animation-engine/`.
- **GSAP exposure ladder (Scroll Motion):** presets → an **Advanced tier** (`advanced` multi-picker: ease / scrub-smoothing / markers) → a read-only **"Show generated GSAP"** panel → a **Motion Snippet** (`custom` effect) that runs author-supplied GSAP, execution-gated to authors with `unfiltered_html` → see `../animation-engine/scroll-motion.md`.
- **Settings/options:** adds a **Site-wide UX** section to Theme Settings (WebGL/background/cursor/page-transition/scroll-loop toggles). Per-element effects are configured on each element's Animations tab (image-picker style pickers).
- **Public hooks/filters:** on-demand CSS/JS partials cooperate with the asset-optimizer combine API (its `css_exclude_handles` filter keeps used-only styles from being double-absorbed). — otherwise mostly self-contained.

## Notes / gotchas

- **Ships inactive by default** — the user activates it in Extensions; nothing renders until then.
- **On-demand loading:** a page ships only the styles/scripts for effects it actually uses ("ship only used styles" contract).
- Requires the `shortcodes` loader + `page-builder` (to surface the 9 elements).
- Repo is **flattened** (`UnysonPlus-Animation-Engine-Extension`, root = the extension folder).
- The authoritative capability inventory is the extension's own `CATALOG.md` — check it before proposing a new module/effect so it stays genuinely distinct.
- Animations/effect pickers use the **popover image-picker multi-picker** shape (label on the top level — see the workspace multi-picker rule).
