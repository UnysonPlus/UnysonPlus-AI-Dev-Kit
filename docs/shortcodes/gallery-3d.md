# `gallery_3d` — Motion Gallery

An animated 3D image showcase — a set of images arranged into a rotating/scrolling/scattered 3D scene (Carousel Ring, Panorama Wall, Card Sphere, Orbit Globe, Sphere Cascade, Totem Wall, Parallax Totem, Card Tunnel, Spiral Stream, Depth Stack, Card Reel, Film Strip, Wheel Carousel, Cover Flow, Carousel Flow, Hero Reel, Focus Slider, Mosaic Marquee, Photo Scatter, Card Stack, Device Cycler). **Requires the `animation-engine` extension active** (without it the tag is unregistered and saved instances render empty). Leaf node: `{ type:'simple', shortcode:'gallery_3d', _items:[], atts:{…} }` — plus the shared wrapper blocks (`common`, `fx`, `spacing`) documented in `README.md`. This file lists only the **shortcode-specific** atts.

## atts
| key | type | default | value shape / choices | what it does |
|---|---|---|---|---|
| `source` | multi-picker | `{kind:'media'}` | `{ kind:'media'\|'posts', media:{images:[…]}, posts:{post_type,count,orderby} }` | Where the cards come from. **Media Library** → `media.images` (multi-upload of `{attachment_id,url}`, order = display order); **Post Type** → builds cards from a post type's featured images (`posts.post_type`, `posts.count` 1–200, `posts.orderby` `date_desc`/`date_asc`/`title`/`menu_order`/`rand`). *(Legacy flat `images` key is still read as a view fallback.)* |
| `design_settings` | multi-picker | `{design:'carousel_ring'}` | see Notes | Chosen 3D design + that design's controls. |
| `as_background` | section-background switch | `'no'` | `'yes'` \| `'no'` | Fill the parent Section and sit behind its content (Stage Height ignored; always auto-animates). |
| `box_style` | box-style picker | box-preset object | box-preset picker object | Reusable Box Preset (border/fill/hover) on each card. |
| `shadow` | box-shadow | `{x:0,y:6,blur:16,spread:-4,color:'rgba(0,0,0,0.35)',inset:false}` | box-shadow object | Card drop shadow. |
| `captions` | select | `'none'` | `none` `hover` `below` | Show a caption per card. |
| `caption_source` | select | `'caption'` | `caption` `title` `alt` `description` | Which Media field feeds the caption. |
| `entrance` | select | `'none'` | `none` `rise` `scale` `blur` `slide` `flip` | Built-in per-card **reveal**, works on EVERY design. It poses the inner content layer (`.tdg__inner`), which the layout never transforms, so it **composes** with the 3D motion instead of fighting it. Each effect fades the image in **one by one** as the gallery scrolls into view, staggered by card index: `rise` (fade + translateY), `scale` (fade + scale 0.82→1), `blur` (fade + de-blur), `slide` (fade + translateX), `flip` (fade + rotateY 70°→0). In pinned Scroll-scrub (see `motion`) it becomes the enter/exit of a full **scroll choreography**: in one-by-one → hold while the design scrubs → out one-by-one. Honours reduce-motion. |
| `entrance_stagger` | slider | `60` | `0`–`90` | Spread of the one-by-one cascade (0 = all together; higher = longer, more staggered). |
| `entrance_distance` | slider | `40` | `0`–`120` (px) | How far each card rises from. |
| `entrance_exit` | switch | `'no'` | `'yes'` \| `'no'` | Also animate OUT (staggered, reverse) as the gallery scrolls off the top. Ignored in pinned Scroll-scrub, where the exit is already part of the choreography. |
| `click` | multi-picker | `{action:'none'}` | `action`: `lightbox` `link` `none` | On card click: **Open Lightbox** (full image in the shared gallery lightbox), **Open Link** (follows each card's link — its post's page for the Post Type source, or the image's "Link URL" for Media Library), or **Do Nothing**. *(Legacy flat `click_action` scalar is still read as a view fallback.)* |

## Notes

- **Card Ratio — shapes, `original`, and sizing** (every design except `card_tunnel`, `device_trio`, `scroll_choreography`; the builder label varies — Tile / Slab / Photo / Screen / Window Ratio — but the key is always `card_ratio`):
  - Fixed ratios `1-1` `4-3` `3-4` `4-5` `16-9` `9-16` set ONE shape for every card; the photo fills the card (`object-fit: cover`), so match the ratio to the photos or they crop.
  - `original` = **Original — mixed**: each card keeps its own image's natural shape (`view.php` emits a per-card `--tdg-ratio: W / H` from the attachment's full-size dimensions via the `$card_style($item)` helper the design views call on each `.tdg__card`). Width stays `card_size`; heights follow the photos. Supported only on `$mix_designs` in `view.php` (cover_flow, carousel_flow, card_reel, film_strip, focus_slider, hero_reel, card_stack, shuffle_deck, card_fan, photo_scatter, polaroid_drop, carousel_ring, spiral_stream, depth_stack). On every other design `view.php` rewrites `$dp('card_ratio')` to `1-1`, so designs that parse the ratio themselves (card_sphere tiling, mosaic_marquee cells, device_cycler screen) render exactly as Square. A bare-URL image (no attachment) has no size → its card keeps the gallery ratio.
  - **`card_size` is a WIDTH** (% of stage); the height = width × ratio. A taller ratio at the same size overflows a short stage and the frame clips it (portrait then reads as square). When you change the ratio, scale the size: `size × old_h/w ÷ new_h/w` (Square 46 → Portrait 3:4 ≈ 34, Tall 9:16 ≈ 26), or raise `height`. The demo builder uses `size = default × min(1.35, r0 / r)` (r = h/w).
  - Adding a design to `$mix_designs`: its view must emit `'<div class="tdg__card"' . $card_style( $item ) . '>'` and its layout must centre each card by its own `offsetHeight` (not one shared card height).

### Adding a new design — the FULL surface (REQUIRED — a design is not done until ALL of these exist)
A Motion Gallery design touches **seven** surfaces, not just the runtime. Missing any one leaves a visible gap
(a fallback ring in the builder, no live preview, an orphaned catalogue card, a stale playground). The checklist:
1. **Plugin runtime** (`framework/extensions/animation-engine/shortcodes/gallery-3d/`): add the slug to `views/view.php` `$designs`; add the picker group + `$<slug>_opts` + the `choices` map entry in `options.php`; create `views/designs/<slug>.php`; write `init<Name>()` + **both** dispatch spots (the scan loop AND `upwGallery3dInitEl`) in `static/js/gallery-3d.js`; add the CSS block in `static/css/gallery-3d.css`; create the animated picker tile `static/img/designs/<slug>.svg`; regenerate the `.min.js`/`.min.css`.
2. **Builder live preview** (`includes/option-types/gallery-3d-preview/static/js/preview.js`): a `DEFAULTS['<slug>']` entry **and** a `buildScene` branch (the file documents these two hooks). Miss the branch and the Design-tab modal previews that design as a **carousel-ring**.
3. **Demo page** (`unysonplus-website/wordpress/demos/11-3d-gallery-demos.php`): a `$designs` list row + an `$examples_map` block + the `$spill_designs` entry; import with `UPW_ONLY=<dashed-slug> UPW_NO_INDEX=1 php 11-3d-gallery-demos.php` (**`UPW_NO_INDEX=1` leaves the catalogue index alone — never `UPW_FORCE` it, that rebuilds/clobbers the catalogue**).
4. **Catalogue preview card** (demos): the `/motion-gallery/` category grid reads `uploads/demo-previews/motion-gallery/<dashed-slug>.jpg`. In ORDER: (a) `D:/xampp/php/php.exe build-preview-manifest.php` — rebuilds `preview-manifest.json` from the DB, so a newly-added/renamed demo page becomes visible to the capture tool (skip this and the capture silently ignores new pages); (b) `node capture-previews.mjs motion-gallery` captures the jpg (never hand-roll; boundingBox() returns viewport coords and mis-scrolls scroll-driven designs); (c) re-run `php 11-3d-gallery-demos.php` (plain, no `UPW_NO_INDEX`) so the catalogue index picks up the new card. All three live in `unysonplus-website/wordpress/demos/`.
5. **Public docs** (`unysonplus-site/animation-engine/elements/motion-gallery/index.md`): a design entry under its family heading.
6. **Kit doc** (this file): the `Designs:` slug list + a per-design controls line below.
7. **Playground** (`unysonplus-site/src/components/Gallery3DPlayground/`): a `scene.js` `buildScene` branch + an `index.js` `DESIGNS` entry (+ its family in `GROUP_ORDER`), then re-run `node src/components/Gallery3DPlayground/vendor.mjs` (whose `initEl` dispatch also needs the design) to re-vendor `gallery-engine.js`. **Then open the BUILT playground in a browser** (`npm run build` → `npx docusaurus serve`, page `/animation-engine/motion-gallery/playground`) and click the new design — a clean build does not prove the playground runs: once the plugin added `IN_EDITOR` to the runtime's head (which `vendor.mjs` strips), the build stayed green while the page threw `IN_EDITOR is not defined` and rendered nothing. `vendor.mjs` now refuses to write the engine when the head declares a name the body uses and the preamble doesn't re-provide; if it stops you, add that name to its preamble.

Then **mirror** the plugin to every localhost install and **bump** the AE `manifest.php`. (Standing instruction, 2026-11-07: don't forget the live preview, the docs AND the playground when adding a design.)

- **Shared controls on the spinning designs** (`carousel_ring` · `panorama_wall` · `card_sphere` · `orbit_globe` · `sphere_cascade` · `totem_wall`): `motion` — an inline multi-picker `{ mode, <mode>:{…} }` whose `mode` is `auto`/`continuous` (branch: `speed` loop seconds, `direction`, `hover_behavior` `none`/`pause`/`slow`), `scroll` (branch: `pin` `'yes'`/`'no'`, `scroll_length` viewports, `rounds` `0.25`–`6` — how far the scrub travels across the pin: **rotational designs** (Ring/Sphere/Orbit) read it as full turns, **flowing scroll-scrub designs** (walls/tunnels/reels/strips) read it as **passes** (the deck travels its length that many times), `direction`), or `static`; `direction` is `left`/`right` (Panorama & Sphere Cascade also `alternate`; Sphere Cascade & Totem Wall use `up`/`down`/`alternate`; Parallax Totem uses `up`/`down`). Plus `allow_drag` (`'yes'`/`'no'`), `drag_momentum` (`'yes'`/`'no'`), `card_ratio` (`1-1` `4-3` `3-4` `4-5` `16-9` `9-16` `original` — see **Card Ratio** below), `corner_radius`, `padding`, `height` (unit-input `px`/`vh`), `overflow` (**Stage Overflow** — every design's frame group: `'clip'` default / `'spill'`; spill lets fanned/oversized cards show in full beyond the stage box — it releases the VERTICAL clip only, keeping horizontal clipped so wide layouts (totem/wall rows) can't trip a page scrollbar; ignored while a Section Background or pinned for scroll-scrub), `background` (compact color, `kind: bg`).
- **Full scroll choreography** (any Scroll-scrub-capable design): set `motion.mode = 'scroll'` with `pin: 'yes'` (+ `rounds` — turns on a rotational design, passes on a flowing one) AND `entrance: 'rise'`. The gallery pins, its images fade in one by one over the first slice of the pin, the design scrubs (the ring/sphere spins its Rounds; a wall sweeps sideways by that many passes) through the middle, then the images dissolve one by one over the last slice — all driven by the visitor's scroll. The reveal rides `.tdg__inner` so it never fights the layout. (Not for the cycle-based designs — `photo_scatter`, `card_stack`, `device_cycler` — which advance sets instead of scrubbing.)
- **Chaining several galleries into one scroll sequence** (design-agnostic): a **top-level** `chain` switch (`atts.chain = 'yes'`, read with `$sc_get` — NOT `$dp`, which is per-design) stamps `data-tdg-chain="1"` on any Scroll-scrub + pinned gallery of ANY design. The runtime `autoGroupChains()` (in `gallery-3d.js`) groups consecutive `.tdg[data-tdg-chain]` galleries — stacked in one column OR each in its own section — into a single `.tdg-choreo-chain` overlay driven by one pinned master ScrollTrigger (gallery 1 exits as gallery 2 enters). The master drives each gallery via `buildChain`: a `.tdg--scroll-choreography` gallery is posed by `choreoPoser().poseAt(p)`; **every other design** gets `__tdgChainProgress = p`, which `scrollProgress()` returns so the design's own already-running loop + its entrance reveal scrub with the chain. `static.php` loads GSAP for a chained gallery too (not just choreography). **Builder shortcut:** right-click a Motion Gallery → **Create choreography** (page-builder context menu, `visual-elements.js`).

Phone Lineup's 3D body follows the screen's COMPUTED opacity + transform while it carries `animate__animated` (and stays hidden under `sc-anim-pending` / `sc-anim-gone`), pivoting about the phone centre, so phones arrive and leave whole. A NEW gallery from the builder palette starts with `config.php` `page_builder.new_atts` = `animation:{effect:'animate__zoomIn'}` + `animation_settings:{sequence:'yes',sequence_stagger:90}` — the page builder applies `new_atts` only to an element dropped from the palette (`simple/static/js/scripts.js`), never as an option default (defaults are merged at render, which would have changed every saved gallery without an `animation` att). Don't combine with the Style-tab Entrance (both pose `.tdg__inner`).
- Switch atts store the string `'yes'`/`'no'`, not booleans.
- Colors (`background`, `box_style`) use the **compact color-preset** shape `{ predefined, custom }`, NOT a raw hex string. See `README.md`.
- Captions/alt read from each image's Media Library fields (per `caption_source`), not from the atts.
